# 꼬물이 한글놀이: 알에서 나비까지 🦋
> 만 4세 유아를 위한 3단계 한글 자음 찾기 및 나비 수집 교육용 웹 게임

🎮 **[실시간 웹 게임 바로 플레이하기](https://songt0204.github.io/hangul-butterfly-game/)**  
*(스마트폰, 태블릿, PC 어디서나 브라우저로 바로 실행됩니다)*

## 📖 프로젝트 소개
**「꼬물이 한글놀이: 알에서 나비까지」**는 만 4세 유아의 발달 수준과 인지 특성을 반영하여 제작된 한글 자음 학습 게임입니다.  
곤충의 한살이(알 ➔ 번데기 ➔ 나비) 자연 생태 학습과 한글 자음(ㄱ ~ ㅎ) 학습을 결합하여, 유아가 즐겁게 퀴즈를 풀며 10종의 다채로운 나비를 수집하고 도감을 완성할 수 있습니다.

---

## ✨ 핵심 기능

1. **알 ➔ 번데기 ➔ 나비 3단계 레벨업 성장 구조**
   - **🥚 1단계 (알 단계)**: 그림과 단어(첫 글자 색상 강조)를 보고 3개 보기 중 첫 자음 찾기 (자음 형태 변별력 훈련)
   - **🌿 2단계 (번데기 단계)**: 그림과 빈칸 단어(`[ ? ] 도`)에 첫소리 자음 쏙 넣기 (음절 결합 훈련)
   - **🦋 3단계 (나비 단계)**: 나비의 음성을 듣고 동일한 스타일의 3개 그림 꽃송이 중 맞는 친구 찾기 (소리 ➔ 어휘 연상 훈련)

2. **반복 플레이 시 매번 바뀌는 동적 단어 풀(Word Bank)**
   - 자음별로 풍성한 대표 어휘(기린, 가지, 고구마, 가방, 개구리 등)를 탑재하여, 게임을 새로 시작할 때마다 문제가 동적으로 출제됩니다.
   - 보기 위치가 무작위(Fisher-Yates Shuffle)로 섞여 정답이 특정 위치에 고정되지 않습니다.

3. **만 4세 맞춤형 UI/UX & Web Speech API (TTS)**
   - 손가락 터치에 최적화된 큼직한 버튼 (72~96px)
   - 글자를 아직 읽지 못하는 유아를 위해 친절한 한국어 음성(TTS)으로 문제를 또박또박 읽어줍니다.
   - 오답 시에도 감점이나 실패 없이 부드럽게 재도전하도록 돕는 긍정적 피드백 시스템.

4. **100% 무중단 Web Audio API 효과음 & 폭죽(Confetti) 연출**
   - 정답 획득 (실로폰 화음)
   - 레벨업 (마법 아르페지오 사운드)
   - 나비 탄생 (웅장한 팡파르 & 축하 컨페티)

5. **10종의 나비 수집 보관함(도감)**
   - 호랑나비, 배추흰나비, 남색모르포나비, 분홍꽃잎나비, 무지개나비, 황금별빛나비 등 10종
   - `localStorage`를 통해 게임을 다시 켜도 수집한 나비가 안전하게 보관됩니다.
   - '처음부터 다시 키우기' 버튼으로 언제든 보관함을 초기화하고 새로 도전할 수 있습니다.

6. **자음 소리 마당 (ㄱ ~ ㅎ)**
   - 14개 자음의 이름, 발음 소리, 대표 단어를 자유롭게 눌러보고 들을 수 있는 미니 놀이터 제공.

## 🚀 시작하기 (Getting Started)

### 요구 사양
- Node.js 18.0.0 이상
- npm 또는 yarn

### 설치 및 실행
```bash
# 1. 저장소 클론
git clone <저장소-URL>
cd <저장소-폴더명>

# 2. 의존성 패키지 설치
npm install

# 3. 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속하여 게임을 플레이할 수 있습니다.

### 빌드하기
```bash
npm run build
```

## 🛠️ 기술 스택
- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Motion
- **Sound & Voice**: Web Audio API (합성 사운드), Web Speech API (SpeechSynthesis)
- **Effects**: canvas-confetti, Lucide React
- **Storage**: Browser LocalStorage
